# 样式徽标 `cls` 类配色文档

博客页的文章卡片支持「样式徽标」（如 置顶 / NEW / HOT）。徽标有两种配色方式：

1. **`color` 字段**（推荐）：在 `STYLE_BADGES` 里直接写一个十六进制色，边框和背景自动按透明度派生，**无需改 CSS**。
2. **`cls` 类**（本页文档）：`cls` 指向一个 CSS 类，由该类提供配色。**当某条 `STYLE_BADGES` 没写 `color` 时**，渲染逻辑会退回使用 `cls` 类。

```js
// 有 color → 用内联颜色（优先）
"固定": { icon: "fas fa-thumbtack", label: "置顶", color: "#ff5a5a" }
// 没 color → 退回 cls 类
"旧":   { icon: "fas fa-clock",     label: "OLD",  cls: "old" }
```

> `cls` 是早期机制，如今已基本被 `color` 取代，但为了兼容旧数据仍保留。新样式优先用 `color`，只有想精确控制边框/背景色时才需要 `cls`。

## 添加一个自定义 `cls` 类

在 `css/blogs.css` 徽标一节追加一段即可。配色规律：文字用较亮的原色，边框/背景用原色的低透明度：

```css
/* 旧：灰色 */
.blog-badge.old {
  color: #c8c8d0;              /* 文字：亮灰 */
  border-color: rgba(150, 150, 170, 0.25);  /* 边框：原色 25% 透明度 */
  background: rgba(150, 150, 170, 0.08);    /* 背景：原色 8% 透明度 */
}
```

然后在 `STYLE_BADGES` 里引用它：

```js
"旧": { icon: "fas fa-clock", label: "OLD", cls: "old" }
```

如果这条样式同时在亮色主题下使用，颜色对比度可能偏低，可再补一组亮色覆盖：

```css
body.light .blog-badge.old {
  color: #6a6a78;
  border-color: rgba(90, 90, 110, 0.25);
  background: rgba(90, 90, 110, 0.08);
}
```

## `color` 与 `cls` 的优先级

渲染逻辑（`blogs/index.html`）：

```js
var rgb = b.color ? hexToRgb(b.color) : null;   // 有 color → 解析成 rgb
if (rgb) {
  // ① 有 color：内联样式直接覆盖，cls 无效
  //    文字 = 原色；边框 = rgba(原色, 0.25)；背景 = rgba(原色, 0.08)
} else {
  // ② 没 color：用 cls 类名拼到 span 上，由 CSS 决定配色
}
```

| 情况 | 结果 |
| --- | --- |
| `color` 存在 | 用内联颜色，忽略 `cls` |
| 只有 `cls` | 用 CSS 类配色 |
| 都没有 | 默认 `.blog-badge`（灰） |
| `color` 非法（写错） | `hexToRgb` 返回 `null`，按「无 color」处理 |

> `color` 支持 3 位缩写（`#f00`）与 6 位（`#ff0000`）。`cls` 的类名会自动拼成 `blog-badge <cls>`，所以类选择器需写作 `.blog-badge.xxx`。
